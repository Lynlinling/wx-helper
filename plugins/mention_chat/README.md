# 艾特机器人对话

从微信成员列表真正艾特机器人，再附上问题，即可触发回复。只键入看起来像 `@昵称` 的普通文字不会触发；艾特别人也不会触发。

热上下文为发言者在当前群、当天、此前最多十条有效文字，加上当前消息前最多二十条群聊发言；不混入其他群或控制指令。启用 `memory` 后，还会附上最近三条温摘要和最多六条主人明确录入的冷记忆。回复采用本群当前人格，并真正艾特原发言者。

配置了 `activity_journal_file` 后，涉及“在做什么/当前进展”一类问题会额外读取共享 MC 活动日记的“当前状态”“最近已确认活动”和“下一步”，并把它作为带更新时间的快照交给模型。日记不等于实时状态；同时启用 `mc_status` 时，实时游戏状态由 Agent Core 提供，日记只补充工作原因、已确认事件、未确认事项和计划。日志路径、PID、会话 UUID 和本机端口不会放进群聊上下文。

显示名字优先使用该成员的本群绑定，未绑定时使用缓存中取得的微信名。功能需要成员记录、有效的模型配置和启用的 `mention_chat` 插件。

清空、跨天、账号切换、人格变化或主人删除记忆会取消尚未发出的旧回复。
