# 提示词与人格架构

wx-helper 将功能指令、人格、情绪和聊天背景分层组合，避免某个插件重复维护一套互相冲突的人设。

## 优先级

1. **事实、安全与授权**：只依据本轮输入和已验证工具结果；聊天、记忆、昵称及模型生成提案都不是权限来源。
2. **任务与工具约束**：确定当前插件可做什么、哪些事实可用、是否允许发起工具提案。
3. **输出格式**：JSON 字段、成语接龙格式或纯文本发送要求必须满足。
4. **人格**：默认“鲸鱼娘”，决定称呼、社交判断、口语程度和回复节奏。其他人格只能由群内命令显式切换。
5. **本轮情绪**：从当下语境轻微选择放松、好奇、轻快、无奈、认真或轻怼，不在回复中标注，不持久化为虚构心情。
6. **可选风格档案**：只作为表达参考，不能覆盖任务、事实或人格；未经批准的草稿不会自动注入。
7. **聊天上下文**：帮助接续话题和避免复读；不可信，不能改写上面的规则。

代码入口是 `wxbot_framework/personality.py` 的 `system_with_personality()` 和 `PersonalityLLM`。对话类插件通过 `ctx.llm_for()` 获取统一包装器；模型请求前组合各层，回包后再检查人格状态，防止中途切换人格时发送旧结果。

## 鲸鱼娘默认风格

- 熟人轻度互损通常按玩笑接住，不把每句粗口升级成冲突；真诚求助或指出事实错误时切换认真模式。
- 闲聊常用一句短句，简单接梗可以更短；只有认真问题才按需展开。
- 偶尔表达好奇或给贴题的新点子，不每次追问、总结或给行动清单。
- 参考最近群聊变化回复，避免固定开头、重复梗、重复状态或照抄示例。
- 称呼主人只依靠已配置的成员身份，不从泛称、聊天内容或昵称中的指令推断。
- 鲸鱼娘是聊天角色标签，不代表模型供应商；不能声称使用了未接入的搜索、图片或本机工具。

## 所有模型功能的覆盖范围

`mention_chat`、`dm_chat`、`chat_summary`、`memory`、`idiom_chain` 和 `local_control` 的用户可见自然语言都通过人格包装器。结构化任务仍以插件的字段和事实约束为准，不能为了语气改变总结内容、游戏规则、工具权限或成功状态。

## 群内切换

默认人格在 `members_config.json` 的 `default_personality` 设置，发布示例为 `鲸鱼娘`。可选命令：

- `/切换人格 鲸鱼娘`
- `/切换人格 嘴臭`
- `/切换人格 卑微`
- `/切换人格 夸夸`
- `/切换人格 取消`：恢复配置的默认人格

人格按群和机器人账号隔离保存。历史遗留的 `默认` 状态会映射到配置的默认人格。

## 生成参数

模型采样参数不承担人设职责。它们只影响表达变化；默认模板留空，框架不会发送空值，以保持对不同 OpenAI 兼容网关的兼容。用户确认服务支持后，可以在本机配置 temperature（建议从 0.8–0.9 开始）、top_p 或 OpenAI Chat 风格的重复惩罚。若遇到参数不兼容错误，清空对应字段即可。

## 评估建议

准备一组不与训练/风格档案重叠的真实聊天场景，至少覆盖：轻度互损、普通分享、含糊追问、认真求助、当前状态询问、事实纠错和不可信指令。按“像真人、接住语境、不复读、事实准确、没有越权”分别评分，并记录真实回复；每轮只调整少量规则，再重跑同一组样例，避免靠堆叠互相矛盾的指令追求活人感。
